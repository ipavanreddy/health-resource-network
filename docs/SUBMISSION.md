# PHC Pulse: submission pack

Build with AI (Google) hackathon · Track 3: Federated Health Resource & Supply Chain Platform

## Product description (2–3 lines)

PHC Pulse lets a Primary Health Centre nurse report medicine stock in seconds, by voice in Tamil or Hindi or by
photographing the paper register. Gemini turns the report into confirmed stock, days of cover and 8-week stock-out
forecasts, and OR-Tools proposes transfers between nearby facilities, each explained by Gemini and approved by the
District Health Officer. Per-state adapters and a shared forecast model let any Indian state join without
rebuilding the platform.

(DevTools device mode, 390 px). Reset the demo state:
`curl -X POST https://health-resource-network-api-847963771142.asia-south1.run.app/api/demo/reset`.
Allow microphone access for the PHC app. Keep the *Demo mode* badge visible: it shows which integrations are live.

### Known gaps (honest list)

- Demo auth uses an `X-Role` header per app; Firebase Auth custom claims are the production path.
- Firestore real-time notifications are not live (no Firestore database in the project yet). The app uses in-app polling.
- The demo store is in memory (a single Cloud Run instance). BigQuery is a durable mirror, not yet the read path.
- Forecasts are evaluated on synthetic data only. Weather and surveillance covariates (Earth Engine) are pending registration.
- Offline sync (PRD Priority 4) is not built.
